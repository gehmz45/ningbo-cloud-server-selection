## VPS 和游戏云差 58 元，差的不是配置高低

同一个宁波机房，雨云卖两种东西，第一次买的人很容易搞混。

云服务器 VPS 是通用虚拟化产品。给你 root、独立 IP，系统镜像覆盖主流 Linux 发行版和 Windows Server，可以一键装宝塔、Docker，开通后几分钟拿到 SSH 凭证。带宽 10M 上传。

游戏云是另一套。CPU 换成 AMD 9950X 这类高主频型号，套餐自带 100G 电信防御，控制台是 MCSM 面板，选好游戏点启动就行。面板里能开的游戏有 Minecraft、饥荒和幻兽帕鲁，也有泰拉瑞亚、Hytale、僵尸毁灭工程和未转变者。规格区间从 2核4G10M 到 8核32G30M，Linux 和 Windows 都支持，SSH、RDP、VNC 都能连。

两者价格差 58 元/月。这 58 元换来的是更高主频、一份防御，以及不用自己配环境。

买哪个取决于你会不会折腾。愿意 SSH 进去装 Java、改 paper.yml、写启动脚本，VPS 完全够用，2核4G 的 VPS 跑十人以内的 MC 服也不是不行。不想碰命令行，或者希望朋友能自己重启、自己加 mod，游戏云省下的时间比 58 元值钱。

反过来，游戏云不适合拿来建站。那份 100G 防御针对的是游戏服常见的 DDoS，建站要的是稳定带宽和磁盘 IO，VPS 那条线更合适。

## 哪些情况不适合买宁波这条线

**需要合同级 SLA 的商业项目。** 雨云是 2018 年成立的中小厂商，公开资料里没有看到 SLA 条款的具体承诺。对稳定性有合同要求、出事要有人兜底的业务，应该走大厂。

**用户主要在海外。** 宁波机房服务的是国内访问。香港、东京、洛杉矶有独立节点，价格和线路都是另一套。

**只想试一次就扔。** 雨云官方退款政策是 7 天无理由，每个账号 3 次机会。但限制不少：领过消费积分、1 元试用后续费、超过 7 天，都不能退。日付、流量包、游戏云电量、加 IP、硬盘和套餐升级这类非月付订单不在退款范围内。限流套餐当天流量超过 100G 会自动失去无理由资格。买之前把这些过一遍，比买完再研究流程省事。

**宁波只是"听起来离我近"。** 先确认你的实际用户在哪。访客七成在珠三角，深圳节点的 48 元/月更合适；玩家集中在武汉、郑州，襄阳那台同配置一年省 184 元。

## 下单前要确认的四件事

1. **宁波是电信单线还是多线 BGP。** 公开资料里宁波的防御标注都写"电信"，线路类型官网没有明确说明。用户里有大量联通、移动的话，先开工单问清楚，或者买月付实测三天。
2. **套餐是否限流量。** 雨云部分地域分"限流量"和"不限流量"两个版本，价格一样，规则不同。选错月底会被限速到 5Mbps，恢复要单独买流量包。
3. **要不要备案。** 大陆机房绑域名对外提供网站服务需要 ICP 备案，这是法规要求，不是商家额外加的门槛。纯 IP 访问、内网服务、游戏服一般不走备案流程，具体支持情况问工单。
4. **续费价。** 折扣规则写的是"所有产品季付 9 折、年付 7 折"，没有标注首购专享，按字面理解续费同样按周期打折。这一点比大厂"首年 68 元、次年原价"要稳，但下单前还是扫一眼续费页。

## 常见问题

**宁波机房是电信单线还是 BGP？**
公开资料只标到"电信"和"电信防御"，没写单线还是多线。买之前开工单问，或者先买月付，用联通、移动网络各测三天延迟再决定要不要年付。

**2核2G 够不够用？**
建站够。WordPress 加宝塔、MySQL、Redis，2G 内存跑得起来，日 IP 上千以后开始吃紧。跑多个 Docker 容器、编译、数据库稍微大一点，直接上 8核16G 那档 188 元/月。游戏服别用 2G，MC 加几个插件就顶到内存天花板，游戏云起步给 2核4G 是有原因的。

**年付能退吗？**
可以，7 天无理由，每个账号 3 次，在控制面板里自助退订。领过消费积分、1 元试用后续费、超过 7 天都不行。日付、流量包、游戏云电量、加 IP、升级这些非月付订单不支持退订。

**首月 5 折怎么拿？**
通过推广链接注册，完成实名认证，绑定微信，券会自动发到账户。有效期和使用范围看券面说明。

**一定要在宁波吗？**
看用户在哪。长三角为主，宁波的延迟优势值这个溢价；华中华北为主，襄阳同配置 50 元/月更合适；只需要最便宜的机器，22 元的宿迁 NAT 或者大厂首购机都能顶。
